# 旧版绕杆策略依赖

本目录保留 `policy.py` 中的 `ActorCritic`、`configs/Q1.yaml`、许可证和来源记录，供旧版绕杆模型适配、控制参数读取及回归测试使用。现行绕杆训练使用任务 7.7 warmup 初始化，说明见[绕杆任务](../../../courses/pole-weaving/README.zh-CN.md)。

踢球采集、数据集处理、足球运行控制、专家回放工具及专属动作数据已移除。此目录不再提供踢球任务运行入口。Q1 配置保持原值，以保证旧版绕杆的网络尺寸、关节顺序和控制参数兼容性。

`SOURCE.json` 是原始提取时的历史来源清单，其文件列表及 checkpoint 路径不代表当前目录仍分发这些文件。保留该记录用于追溯；许可证见 [LICENSE](LICENSE)。
